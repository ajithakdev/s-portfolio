Personal portfolio showcasing production backend engineering achievements in healthcare SaaS at **The Valor Solution**, open-source systems (`toolglass`, `MeterX`, `clip-paste`, `CNoBS`), and cloud architecture.

## 🛠️ Tech Stack

- **Frontend:** React 18, Styled Components, Framer Motion, Three.js / React Three Fiber
- **Production Experience Showcased:** Node.js, TypeScript, Express.js, Amazon DocumentDB, MongoDB, AWS (S3, SQS, SES, Lambda), pytest, Docker, GitHub Actions CI/CD

## 🚀 Local Development

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm start

# Build for production
npm run build
```
